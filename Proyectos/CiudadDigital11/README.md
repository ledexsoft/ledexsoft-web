# Documentación de Ciudad Digital 1.1

Micrositio estático sin framework ni dependencias externas. GitHub Pages lo sirve desde la raíz del sitio LedexSoft en:

`https://ledexsoft.com/Proyectos/CiudadDigital11/`

## Contenido

- `index.html`: punto de entrada y resumen del estado.
- `plan.html`: alcance, mecánicas, hitos y tablero de progreso.
- `desarrolladores.html`: explicación técnica, preparación del código, datos geográficos y contribución.
- `css/docs.css`: estilo responsive del micrositio.

Los cambios de estado deben cotejarse con el código y el editor antes de publicarse. Se marca explícitamente lo que compila y lo que ha sido validado en Unreal/PIE.
