CumaPlay para Android

Versión de prueba · 1.3

La versión 1.3 pinta una base de color para el terreno y conserva las calles sencillas del centro de Cumanayagua. El agua cartografiada se indica con color; no hay agua física ni edificios nuevos. El trazado y las zonas pintadas siguen © OpenStreetMap contributors y el relieve de Copernicus DEM GLO-30. Los anchos y el material son provisionales.

Un solo APK con los datos del juego incluidos. No necesita un archivo OBB adicional.

Requisitos: Android 8.0 o posterior y procesador ARM64. No es compatible con iPhone ni con Android de 32 bits.

Descargar APK · 130,2 MBDescarga alojada en GitHub Releases. Archivo: CumaPlay-Android-arm64-v4.apk

Cómo instalar

  1. Descarga el APK en tu teléfono Android.
  2. Abre el archivo desde Descargas. Si Android lo pide, permite a esa aplicación instalar esta descarga de origen externo.
  3. Completa la instalación y abre CumaPlay. Si ya tienes la versión anterior, instala esta actualización encima, sin desinstalar.

Importante: esta versión se ha probado en un entorno Android ARM64 emulado, con Vulkan y sin internet. La versión 1.3 aún no se ha probado en un teléfono físico; el rendimiento y la compatibilidad de cada dispositivo están pendientes de comprobar.
